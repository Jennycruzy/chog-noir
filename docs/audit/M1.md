# Core data review

Review branch: `data-engine`. M0 remains open; this work has not been merged into main. No live case has been published.

## What this supplies each day

The case builder can read supported sales with exact payments, the Chogs involved, their ownership periods, previous owner counts, repeat buyers and sellers within a UTC day, and the seven preceding sales used for a price reference. Each calculated fact retains its source records. Unclear events stay on the review list.
